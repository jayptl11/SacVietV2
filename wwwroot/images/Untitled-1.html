PROJECT WEBSITE SACVIET

1. TỔNG QUAN DỰ ÁN

1.1 Giới thiệu

SacViet là một website tin tức về văn hóa Việt Nam, được xây dựng theo phong cách VietnamPlus.vn. Website cho phép:

  • Đọc tin tức theo chuyên mục
  • Quản lý bài viết (Writer/Admin)
  • Đăng nhập/Đăng ký (hỗ trợ Google OAuth)
  • Tìm kiếm nâng cao

1.2 Công nghệ sử dụng

Thành phần Công nghệ
Framework ASP.NET Core 8.0 (Razor Pages / MVC)
Database SQL Server + Entity Framework Core
Authentication Cookie Authentication + Google OAuth 2.0
Frontend Bootstrap 5, Font Awesome 6, jQuery
Architecture Repository Pattern + Service Layer

4. LUỒNG XÁC THỰC (AUTHENTICATION FLOW)

4.1 Đăng nhập thông thường

Sequence Diagram: Login Flow

  1. User → AccountController: POST /Account/Login
  2. AccountController → AuthService: LoginAsync()
  3. AuthService → Database: GetByEmailAsync()
  4. AuthService: VerifyPassword()
  5. AccountController: Create Claims & Cookie
  6. Redirect to Home

4.2 Đăng nhập Google OAuth

Sequence Diagram: Google OAuth Flow

  1. User → AccountController: GET /Account/GoogleLogin
  2. Redirect to Google Authorization
  3. User authorizes app
  4. Google → AccountController: Callback with claims
  5. AccountController → AuthService: GetOrCreateGoogleUserAsync()
  6. Check/Create user in Database
  7. Create Claims & Cookie
  8. Redirect to Home

7. TÍNH NĂNG ĐẶC BIỆT

7.1 Web Crawler

  • Tự động lấy nội dung từ URL bài báo khác
  • Trích xuất: Title, Summary, Content, Thumbnail
  • Download ảnh về server local

7.2 Scheduled Publishing

  • Hẹn giờ đăng bài tự động
  • Background Service chạy định kỳ kiểm tra và publish

7.3 Google Drive Audio Support

  • Chuyển đổi URL Google Drive thành playable URL
  • Hỗ trợ nhiều format: /file/d/ID/view, open?id=ID

7.4 Vietnamese Slug Generation

  • Tự động chuyển đổi tiếng Việt sang không dấu
  • Thêm timestamp để đảm bảo unique

8. BẢO MẬT

Tính năng Triển khai
Password Hashing SHA256
CSRF Protection [ValidateAntiForgeryToken]
Cookie Security HttpOnly, Secure, SameSite=Lax
Authorization Role-based ([Authorize(Roles = "Writer,Admin")])
Input Validation Data Annotations + ModelState
XSS Prevention HTML Encode (WebUtility.HtmlDecode)
